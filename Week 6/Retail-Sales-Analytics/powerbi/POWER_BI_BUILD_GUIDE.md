# Power BI Dashboard Build Guide

## 1. Import data
1. Open Power BI Desktop.
2. Home → Get data → Text/CSV → select `data/cleaned_sales.csv`.
3. In Power Query, confirm `Order_Date` is Date; Quantity whole number; Unit_Price, Discount, Sales, Profit decimal; other fields text.
4. Choose Close & Apply.

## 2. Create measures (Modeling → New measure)
```DAX
Total Sales = SUM('cleaned_sales'[Sales])
Total Profit = SUM('cleaned_sales'[Profit])
Total Orders = DISTINCTCOUNT('cleaned_sales'[Order_ID])
Units Sold = SUM('cleaned_sales'[Quantity])
Profit Margin % = DIVIDE([Total Profit], [Total Sales], 0)
Average Order Value = DIVIDE([Total Sales], [Total Orders], 0)
Average Discount % = AVERAGE('cleaned_sales'[Discount])
```
If Power BI names your table differently, replace `'cleaned_sales'` with the actual table name.

## 3. Suggested one-page layout (16:9)
- Header: **Retail Sales & Business Performance Dashboard**
- Top row KPI cards: Total Sales, Total Profit, Total Orders, Profit Margin %
- Middle left: line chart — Order_Date (Month) vs Total Sales
- Middle right: clustered bar chart — Category vs Total Sales and Total Profit
- Bottom left: bar chart — Region vs Total Sales
- Bottom middle: bar chart — Product vs Total Sales (Top N = 10)
- Bottom right: donut chart — Customer_Segment vs Total Sales
- Slicers: Order_Date, Region, Category, Customer_Segment, Payment_Method

## 4. Formatting and interactivity
- Use consistent currency formatting for Sales and Profit; percentage format for Profit Margin % and Average Discount %.
- Sort monthly trend by date (not alphabetically by month name).
- Add data labels where readable and descriptive titles.
- Use Edit interactions to ensure slicers filter all relevant visuals.
- Add tooltip fields: Total Profit, Profit Margin %, Units Sold.
- Add a small note: “Synthetic demonstration dataset; results are illustrative, not actual company performance.”

## 5. QA checklist
- Check cards update when slicers change.
- Confirm Total Orders counts distinct Order_ID values.
- Confirm no invalid negative quantities or discounts outside 0–100%.
- Compare dashboard totals with Python output.
- Save as `powerbi/retail_sales_dashboard.pbix`.

## Important limitation
This package includes this build guide and DAX measures, not a compiled `.pbix` file. The `.pbix` must be created and saved using Power BI Desktop, which is not generated by this Python package.
