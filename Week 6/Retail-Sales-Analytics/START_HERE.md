# Start Here

1. Read `README.md` and note the synthetic dataset limitation.
2. Install requirements: `pip install -r requirements.txt`
3. Run `python src/data_analysis.py` or open `notebooks/retail_sales_analysis.ipynb`.
4. Review charts in `visualizations/`.
5. Build the dashboard in Power BI Desktop using `powerbi/POWER_BI_BUILD_GUIDE.md`.
6. Follow `docs/git_workflow.md` to create a GitHub repository and push 3 meaningful commits.
7. Review `report/final_project_report.pdf` and `presentation/retail_sales_analytics_presentation.pptx`.

## Package status
- Included: CSV dataset, cleaning/EDA code, notebook, 7 PNG charts, report PDF, PPTX presentation, README, Git workflow, DAX measures, Power BI build guide.
- Not included: compiled Power BI `.pbix` file; create it in Power BI Desktop.
- Dataset status: synthetic educational demo. Replace with a cited public dataset if the assignment strictly requires real-world data.
