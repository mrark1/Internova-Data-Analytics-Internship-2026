# Data Dictionary

| Column | Meaning | Type |
|---|---|---|
| Order_ID | Unique transaction/order identifier | Text |
| Order_Date | Order date | Date |
| Region | Sales region | Category |
| Category | Product category | Category |
| Product | Product name | Category |
| Quantity | Units in order | Integer |
| Unit_Price | Price per unit, generic currency | Decimal |
| Discount | Discount fraction from 0 to 1 | Decimal |
| Sales | Net sales after discount | Decimal |
| Profit | Estimated transaction profit | Decimal |
| Customer_Segment | Customer group | Category |
| Payment_Method | Payment channel | Category |

**Synthetic data warning:** values are generated for demonstration and should not be interpreted as real company records.
