## How to run
1. Install Python 3.10+.
2. Open a terminal in the `scripts` folder.
3. Install dependencies:
   `pip install -r ../requirements.txt`
4. Run any task:
   `python task01_numpy_arrays.py`
5. Tasks 5–10 use the CSV files in `../datasets/` and write processed files to `../outputs/`.
